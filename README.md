# blog beeth73 // log

> "Deconstructing concepts to reconstruct understanding."

This is a personal technical journal and a playground for high-performance web engineering. Built with the belief that the "soul" of software lives in the details, not the dependencies.

## 🛠 The Tech Stack (Vanilla Maxxing)
- **Engine:** Vanilla JavaScript (ES6+). No frameworks, no bloat.
- **Renderer:** WebAssembly (WASM) for client-side Markdown-to-HTML parsing.
- **Architecture:** Static-Site-Generation logic executed on the client-side.
- **Hosting:** GitHub Pages.

## 🧠 Philosophy
1. **Low Overhead:** The site should be a "brick"—solid, fast, and functional on any device.
2. **Maintainable Mastery:** Documented, structured, and readable code. Comments are treated as part of the architecture.
3. **The Human Clause:** While AI may assist in boilerplate logic or debugging, every word of personal expression, technical pov, and artistic direction is 100% human-generated.

## 📂 Structure
- `/assets`: The central nervous system (JS, CSS, WASM).
- `/posts`: Raw Markdown files containing the "soul" of the blog.
- `sitemap.json`: The registry of all published logs.

## 🚀 Deployment
Every `git push` triggers a live update via GitHub Pages.
